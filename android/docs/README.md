# Android Documentation

Plain-English guides explaining how the Android app works, why it behaves the way it does on modern phones, and how to solve Android-specific connection issues.

For background that applies to both Desktop and Android—like why modern browsers block `192.168.1.1` or which device compatibility profile to pick—see the [Desktop Documentation](../../desktop/docs/README.md).

## Guides

- [How the Android App Works](how-it-works.md) — How the on-device bridge connects to old hardware, in-app vs. external browser viewing, and why an active notification appears while running.
- [Android Design & Platform Decisions](design-and-platform-decisions.md) — Why the app uses a foreground notification, per-session local addresses, a bundled legacy encryption engine, and minimal permissions.
- [Android Troubleshooting](troubleshooting.md) — Fixing Wi-Fi/VPN/mobile-data routing, battery-saver interference, notifications, and stopping the proxy.
